{#- The form's field widgets: one block per writable column, driven entirely by the published `_meta` columns. Included by both hosts — `table.html`'s create/edit modal and `form.html`'s standalone card — so a widget added here appears in both. Context-free: every value comes from the Alpine component (`_form_core.html`), nothing from the template struct, which is why the same file works for two different structs. Exactly one branch matches per column: `widgetOf(c)` resolves a single widget name (an explicit `display` override, else derived from the type), so adding a widget means adding one branch here and one case there — not editing a chain of conditions that must stay mutually exclusive. -#}
